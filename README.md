# Custom Blog CMS Backend

This is a reusable CMS backend built with **Node.js**, **Express**, and **MongoDB**, designed to power multiple blogs with simple, flexible REST API endpoints.

---

## 🚀 Features

- 📝 Blog Post CRUD (Create, Read, Update, Delete)
- 🔐 JWT Authentication (Admin-only protected routes)
- 🧰 Modular project structure
- ☁️ Ready for image upload (Cloudinary/S3)
- 🌐 Easily connectable to any frontend (React, Vue, etc.)

---

## 📦 Tech Stack

- Node.js
- Express.js
- MongoDB (via Mongoose)
- JSON Web Tokens
- dotenv
- CORS
- bcryptjs
